# Living Waters Cleanse — 10-Day Retreat Landing Page (sample)

A static review build of the landing page for the **10-Day Cleanse & Healing Retreat**, prepared by Boise Marketing Mechanic.

- `index.html` is a single self-contained page: no build step, no dependencies. Fonts load from Google Fonts.
- The page has `noindex, nofollow` set so search engines skip it while it's a draft. Remove that line before it goes live.
